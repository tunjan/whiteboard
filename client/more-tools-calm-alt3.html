Alternative 3

Tonal Hierarchy & Inline Disclosure

In the Calm UI design system, components containing rich ink typography avoid jarring solid ink fills. Alternative 3 deploys the Tonal Moss accent language (bg-moss-wash text-moss), creating a restful, botanical focal point.

1

Tonal Moss Active State

Active tools use bg-moss-wash text-moss with an energetic yet calm indicator dot. Replaces harsh high-contrast black fills with warm grounded tonal hierarchy.

2

Inline Disclosure (Zero Cascading Flyouts)

Solves tablet & touch frustrations. Floating submenus frequently clip screen edges and dismiss inadvertently. In Alternative 3, clicking "Polygons", "Stickers", or "Media" slides smoothly inside the single 18px panel container.

3

Spacing is the Only Separator

Strict adherence to Calm UI: Zero divider border lines between peer tools. Rhythmic vertical pacing (space-y-3 between clusters, space-y-0.5 between items) creates clean grouping without visual noise.

4

Tonal Tool Lock Switch

Tool lock (hotkey Q) uses a dedicated tonal moss pill toggle. When engaged, the lock illuminates in moss wash with a crisp visual cue.

Accessibility (WCAG 2.2 AA / AAA)

  • Role semantics: menu container with menuitemradio for exclusive tools and menuitemcheckbox for Tool lock.
  • Color contrast: Moss #27604A on Moss-wash #E0EFE5 achieves 4.8:1 contrast ratio (surpasses WCAG AA 4.5:1 text standard).
  • Keyboard interaction: Arrow Up/Down traverses items; Right Arrow or Enter drills into submenus; Left Arrow or Escape returns to parent view.
  • Focus ring: Dual-ring focus indicator matching Calm UI token palette without outline clipping.
