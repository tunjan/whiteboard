Systems Blueprint

Calm UI Toolbar Satellite Bar Specification

Formal architectural rules, grouping mechanics, accessibility matrix, and comparative analysis.

Zero Peer Dividers

Standard toolbars slice every group with harsh 1px vertical borders (tbar-separator). In Calm UI, peer separators are entirely eliminated. The eye parses grouping through pure spatial rhythm: 2px between related keys, 10px between conceptual clusters.

Target Budget (≥40px)

Every interactive key satisfies WCAG 2.5.5 Level AAA hit-target guidelines with minimum dimensions of 40×40px (size-10). Icons are optical-grade 20px glyphs rendered with unified stroke-width: 1.7.

Tonal State Accent

To prevent visual fatigue, color is strictly restricted to one single ink-grade accent: --color-moss (#27604A) and its wash tint --color-moss-wash (#E0EFE5). Only modified, non-default styles earn this tone.

Accessibility & Keyboard Interaction Contract

Both alternatives strictly follow WAI-ARIA Toolbar and Radiogroup design patterns:

  • Roving Tabindex: Exactly one button in each radiogroup holds tabindex="0"; all peer options have tabindex="-1".
  • Arrow Navigation: ArrowLeft and ArrowRight cycle selection and shift browser focus seamlessly.
  • Escape Dismissal: Pressing Escape immediately collapses any open popover or the unified tray and returns focus to its trigger key.
  • Screen Readers: Clear, localized labels e.g. aria-label="Fine stroke, 2 pixels", aria-checked="true", and role="radiogroup".
