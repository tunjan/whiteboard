Design Decisions Summary: Alternative 3

Calm UI design choices governing the Ambient Drawer / Perimeter Rail.

1. Zero Peer Dividers

Strict adherence to the Calm UI rule: never dividers or separator lines between peer controls or list rows. Structural groups rely exclusively on the 4px grid (gap-0.5 inside groups, gap-2.5 between sections). Hairline border border-line is reserved solely for the outer boundary of the rail.

2. Calm State Hierarchy

Speaking state avoids loud badges or pulsing rings around the whole card. Instead, three organic audio level dots (size-1.5) gently illuminate in text-moss. Listening is a true null state with near-invisible resting dots. The primary ink fill (bg-ink text-paper) is kept solely for active key actions like Push-to-Talk.

3. Accessibility (A11y)

All controls clear the 40px hit-target requirement (size-10 minimum). High-contrast typography (all contrast ratios >= 5.2:1 against paper surface). Live speech and participant updates use polite aria-live regions and standard button roles (aria-pressed, aria-expanded).
